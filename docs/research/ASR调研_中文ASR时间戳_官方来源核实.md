### A-2 结论（5 条）

1. **版本与许可证要分开看**：工具包 `funasr` 当前稳定版 **1.4.16**，代码是 **MIT**；但预训练权重是**独立授权**，官方明确要求「以各模型卡上的许可证为准」。Paraformer-zh 在 ModelScope 与 Hugging Face 上标注的都是 **Apache-2.0**。([PyPI](https://pypi.org/project/funasr/)、[MODEL_LICENSE](https://github.com/modelscope/FunASR/blob/main/MODEL_LICENSE)、[ModelScope Paraformer](https://www.modelscope.cn/models/iic/speech_paraformer-large_asr_nat-zh-cn-16k-common-vocab8404-pytorch))
2. **字级时间戳是官方明示能力**：中文官方文档写「含有字级别时间戳」，SDK 的 `timestamp` 为毫秒级 token/字符区间对，句级为 `sentence_info.start/end`（毫秒）；ONNX 二进制还能直接吐 JSONL。([离线转写指南](https://github.com/modelscope/FunASR/blob/main/runtime/docs/SDK_advanced_guide_offline_zh.md)、[ONNX 输出契约](https://www.funasr.com/en/docs/onnx-output.html))
3. **CPU 无 GPU 场景有官方量化路线与官方 RTF 数据**：ONNX + int8 量化后模型仅 237MB、CER 不变（1.95%），16 核带 avx512_vnni 的 Xeon 单并发 RTF 0.028（≈35×），无 avx512_vnni 的老 CPU 单并发 RTF 0.075（≈13×）。([CPU 基准](https://github.com/modelscope/FunASR/blob/main/runtime/docs/benchmark_onnx_cpp.md))
4. **标点、说话人分离都不默认开启**：`ct-punc` 与 `cam++` 都需显式配置；两者在 ModelScope 与 HF 上均标 Apache-2.0。官方特别提示说话人索引只是「本段录音内的匿名编号」，不跨录音稳定、不是身份识别。([SDK 文档](https://github.com/modelscope/FunASR/blob/main/docs/python_api.md))
5. **SenseVoice 与 Paraformer 是互补关系**：官方推荐「CPU / 多语种 / 要情感与音频事件 → SenseVoice-Small」，「纯中文 + 要字级时间戳或热词 → Paraformer」。SenseVoice 的时间戳要显式开 `output_timestamp=True`，且官方声明其对齐单元不等于显示文本的逐字符索引。([模型选择指南](https://github.com/modelscope/FunASR/blob/main/docs/model_selection.md))

### B-2 结论（5 条）

1. **三个项目的许可证不同，且都很宽松**：openai/whisper **MIT**（代码+权重）、faster-whisper **MIT**、WhisperX **BSD-2-Clause**。([whisper LICENSE](https://github.com/openai/whisper/blob/main/LICENSE)、[faster-whisper LICENSE](https://github.com/SYSTRAN/faster-whisper/blob/master/LICENSE)、[WhisperX LICENSE](https://github.com/m-bain/whisperX/blob/main/LICENSE))
2. **原版 Whisper 的 word_timestamps 官方自标 “experimental”**；且 WhisperX 官方 README 直接承认 Whisper 原生时间戳是句级、**可能偏差数秒**——这正是 WhisperX 引入 wav2vec2 强制对齐的原因。([transcribe.py](https://github.com/openai/whisper/blob/main/whisper/transcribe.py)、[WhisperX README](https://github.com/m-bain/whisperX))
3. **中文强制对齐模型确实存在且许可证干净**：WhisperX 内置 `jonatasgrosman/wav2vec2-large-xlsr-53-chinese-zh-cn`（apache-2.0），中文走字符级对齐分支。但官方同时声明：**数字/货币等不在对齐字典里的词会拿不到时间戳**。([alignment.py](https://github.com/m-bain/whisperX/blob/main/whisperx/alignment.py))
4. **CPU 加速倍数只有 faster-whisper 有官方说法**：「同精度下最高 4 倍于 openai/whisper」，并附 8 线程 i7-12700K 的 small 模型实测（int8 + batch 8 从 6m58s 降到 51s）。**openai/whisper 官方只给显存与 A100 相对速度，没给 CPU RTF**。([faster-whisper README](https://github.com/SYSTRAN/faster-whisper#benchmark))
5. **关于「带 BGM 的广告口播」，官方没有任何针对性说明**；能拿到的证据是：OpenAI 侧只有缓解参数（`hallucination_silence_threshold` 等），学术侧有 ICASSP 2025 论文证实非语音音频会诱发 Whisper 高频幻觉，社区侧有「中文 + 纯背景噪声 → 输出固定无关文本」的讨论 #2645。WhisperX 官方缓解手段是 VAD 分段 + 关掉 `condition_on_prev_text`。([arXiv:2501.11378](https://arxiv.org/abs/2501.11378)、[Discussion #2645](https://github.com/openai/whisper/discussions/2645))

### C-2 结论（5 条）

1. **「字级时间戳」三家不同**：阿里云与腾讯云**能拿到词级时间戳但都需要显式开启参数**——阿里云要 `enable_words=true` **且** `version="4.0"`（词级单位毫秒），腾讯云要把 `ResTextFormat` 设为 `1/2/3`（`3` 官方标注「适用字幕场景」）；**百度智能云的音频文件转写当前只到句段级**，字粒度字段 `words_info` 官方标为「预留参数，暂不启用」。([阿里云接口说明](https://help.aliyun.com/zh/isi/developer-reference/api-reference-2)、[腾讯云 CreateRecTask](https://cloud.tencent.com/document/product/1093/37823)、[百度音频文件转写API](https://cloud.baidu.com/doc/SPEECH/s/Klbxern8v))
2. **离线按量价格量级：大致 1.5–2.5 元/小时**。阿里云录音文件识别后付费标准价 **2.50 元/小时**（5000h 以上降至 1.00）；腾讯云预付费最低档 **1.5 元/小时**（60 小时包 90 元）；百度音频文件转写后付费 **2 元/小时**、音视频字幕（中文）**2.5 元/小时**。腾讯云另有**每月 10 小时**录音文件识别免费额度。([阿里云计费方式](https://help.aliyun.com/zh/isi/product-overview/billing-10.md)、[腾讯云计费概述](https://cloud.tencent.com/document/product/1093/35686)、[百度语音识别计费](https://cloud.baidu.com/doc/SPEECH/s/Tldjm0i4c))
3. **说话人分离三家都有，但适用条件差别很大**：腾讯云是**通用能力**（多数 16k 中文引擎可选、单声道、自动最多 20 人）；百度**只有 `pid=8953` 这个模型支持**；阿里云**限制最严**——官方回答称目前仅 8k 单通道可角色分离，16k 版本当时未对外开放。([腾讯云 CreateRecTask](https://cloud.tencent.com/document/product/1093/37823)、[百度音频文件转写API](https://cloud.baidu.com/doc/SPEECH/s/Klbxern8v)、[阿里云官方回答](https://developer.aliyun.com/ask/645853))
4. **私有化部署的公开程度差异明显**：腾讯云有公开的**离在线 SDK** 文档（纯离线模式仅支持实时语音识别接口、仅企业认证账号、定位为兜底场景）；百度有公开的**私有化部署方式**页（纯软件版 / 一体机版，付费项目、价格需申请）；**阿里云智能语音交互的私有化产品页本次未能确认**。([腾讯云离在线 SDK](https://cloud.tencent.cn/document/product/1093/87618)、[百度私有化部署方式](https://cloud.baidu.com/doc/SPEECH/s/Plwrmqict))
5. **与「叠加字幕」直接相关的官方线索**：腾讯云 `ResTextFormat=3` 明确写「适用字幕场景」且可配 `SentenceMaxLength`（单标点最多字数，范围 [6,40]）控制单行字幕最大字数；百度另有独立的「音频文件转写-音视频字幕（中文）」接口（`pid=80006`，可返回 `voice_power`），后付费 2.5 元/小时；阿里云录音文件识别接口有 `sentence_max_length`（每句最多展示字数，取值范围 [4,50]），官方说明原文「该参数可用于字幕生成场景，控制单行字幕最大字数」，另有 `punctuation_mark` 可自定义断句标点。([腾讯云 CreateRecTask](https://cloud.tencent.com/document/product/1093/37823)、[百度音频文件转写API](https://cloud.baidu.com/doc/SPEECH/s/Klbxern8v)、[阿里云接口说明](https://help.aliyun.com/zh/isi/developer-reference/api-reference-2))
